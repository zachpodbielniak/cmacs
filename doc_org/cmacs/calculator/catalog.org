This is the complete reference to every named calculator, generated from
the registry that also backs the landing page, completion and the MCP
tools — so it cannot drift from the functions actually defined.  For the
GNU Calc built-ins these compose with, see [[file:builtins.org][the built-ins catalog]].  Read
[[file:index.org][the guide]] first for the corrected semantics, and see
[[file:reference.org][the option & API reference]] for the surrounding machinery.

Every calculator is a first-class GNU Calc algebraic function (defined with
=cmacs-calculator-defcalc=), so it composes inside any larger expression and
works from a sheet, the REPL, inline =C-c ==, and =emacs --calc=.  Each example
below is *real output* from the engine.  Physics and relativity arguments and
results are in base SI units (metres, kilograms, seconds, kelvin, coulombs,
joules), and every angle is in radians; relativity takes speed as =beta=, a
fraction of the speed of light.
