* Overview

cmacs-whisper integrates [[https://github.com/ggerganov/whisper.cpp][whisper.cpp]] for offline speech-to-text.
Models are loaded on first reference and cached in a thread-safe
~path → struct whisper_context*~ map; inference runs on a GThread
worker so the Emacs main thread never blocks.  Completion is
delivered back to the main thread via
~g_main_context_invoke (cmacs_glib_get_context())~.

* Requirements

** Build flags

#+begin_src text
--with-cmacs-audio      # required (PCM input plumbing)
--with-cmacs-whisper    # this subsystem
#+end_src

** whisper.cpp

The configure script tries system ~whisper.pc~ first, then falls back
to a bundled ~deps/whisper.cpp~ submodule.  Recent whisper.cpp is
CMake-only — the in-tree build runs:

#+begin_src bash
git submodule update --init deps/whisper.cpp
cd deps/whisper.cpp
cmake -B build -DBUILD_SHARED_LIBS=OFF -DGGML_OPENMP=OFF \
      -DWHISPER_BUILD_TESTS=OFF -DWHISPER_BUILD_EXAMPLES=OFF \
      -DCMAKE_C_STANDARD=11 -DCMAKE_CXX_STANDARD=17 \
      -DCMAKE_C_STANDARD_REQUIRED=ON -DCMAKE_CXX_STANDARD_REQUIRED=ON
cmake --build build --config Release --parallel
#+end_src

The ~src/Makefile.in~ rule fires this automatically on first
`make`.  The ~CMAKE_C/CXX_STANDARD~ flags work around a CMake 4.x
feature-detection table that doesn't yet know about GCC 16+
(without them ~target_compile_features(... c_std_11 cxx_std_17)~
errors at configure time).

cmacs links the resulting static archives in this order:

#+begin_src text
deps/whisper.cpp/build/src/libwhisper.a
deps/whisper.cpp/build/ggml/src/libggml.a
deps/whisper.cpp/build/ggml/src/libggml-cpu.a
deps/whisper.cpp/build/ggml/src/libggml-base.a
-lm -lstdc++ -lpthread
#+end_src

Build host needs a C++ compiler (~gcc-c++~ on Fedora, ~g++~ on
Debian).  ~install-deps~ pulls it in via ~PKGS_AUDIO~.

** Models

Models are looked up via ~cmacs-whisper-models-search-path~:

1. ~~/.local/share/cmacs/whisper-models/~ — user dir, writable by
   ~M-x cmacs-whisper-download-model~.
2. ~/usr/share/cmacs/whisper-models/~ — system dir, populated by
   container image builds (see ~build-container~).  The bundled
   default English model (~ggml-base.en.bin~, 142 MB) lands here.

User-installed models take precedence.  Override the bundled model
at image-build time:

#+begin_src bash
WHISPER_MODEL_NAME=ggml-small.en.bin \
WHISPER_MODEL_URL=https://huggingface.co/ggerganov/whisper.cpp/resolve/main/ggml-small.en.bin \
  ./build-container
#+end_src

Manual download to the user dir:

#+begin_src elisp
M-x cmacs-whisper-download-model RET ggml-base.en.bin RET
#+end_src

Recommended starter set:

| Filename | Disk | RAM | Notes |
|----------+------+-----+-------|
| ~ggml-tiny.en.bin~  | 75 MB | 125 MB | Real-time on CPU |
| ~ggml-base.en.bin~  | 142 MB | 210 MB | Good default |
| ~ggml-small.en.bin~ | 466 MB | 600 MB | Better accuracy |
| ~ggml-medium.en.bin~ | 1.5 GB | 1.7 GB | Accurate, slow |

* Architecture

** Async job lifecycle

1. Lisp calls ~cmacs-whisper-transcribe-async~ with model path,
   language, WAV/PCM, callback, and an optional thread count.
2. C side packages a ~CmacsWhisperJob~ + spawns a ~GThread~.
3. Worker calls ~whisper_full~ (synchronous, off the main thread).
4. Worker calls ~g_main_context_invoke~ to hand the result back.
5. Main-thread completion handler converts segments into a Lisp
   alist and calls the registered callback via ~safe_calln~.

** Model cache

~cmacs/whisper/cmacs-whisper-context.c~ holds a single
~GHashTable~ keyed by model path.  Lookup is single-mutex; the load
path is only contended on the very first reference per model.  No
eviction at v1.

** Concurrent jobs on one model

A ~whisper_context~'s weights are shareable between threads, but its /default state/ — the scratch space ~whisper_full~ writes — is not.  Overlapping jobs on one model are normal: the voice loop runs partial, wake-word and final transcriptions that overlap, and cmacs-transcribe runs files in parallel.  Each job therefore calls ~cmacs_whisper_context_claim_default~ (non-blocking): the winner uses the default state, any other job allocates a private one with ~whisper_init_state~ and runs ~whisper_full_with_state~, then frees it.  Weights stay shared, inference stays parallel, and no two threads ever write one state.  (Before this, two overlapping jobs on one model ran ~whisper_full~ on the same state.)

** Log filter

whisper.cpp and ggml log several INFO lines per call, and the streaming VAD is called ten times a second — under ~--gowl~ stderr is the journal.  ~init_cmacs_whisper~ installs a ~whisper_log_set~ callback that passes only WARN and ERROR (continuation lines follow their first line).  Set ~CMACS_WHISPER_DEBUG=1~ in the environment to see everything.

** Streaming VAD

whisper.cpp v1.9 ships the Silero voice-activity model in ggml form and exports ~whisper_vad_detect_speech_no_reset~, which keeps the model's LSTM state across calls — what a live microphone needs.  cmacs exposes it as a handle-based stream:

| DEFUN | Purpose |
|-------+---------|
| ~(cmacs-whisper-vad-open MODEL &optional THREADS)~ | New stream; signals if MODEL does not exist.  The model is loaded by the worker on the first feed, so opening never blocks on I/O |
| ~(cmacs-whisper-vad-feed HANDLE PCM CALLBACK)~ | Queue S16LE 16 kHz PCM; CALLBACK later gets ~((:probs . [P ...]) (:window . 512))~ or ~((:error . MSG))~ |
| ~(cmacs-whisper-vad-reset HANDLE)~ | Reset the LSTM state (queued behind earlier feeds) |
| ~(cmacs-whisper-vad-close HANDLE)~ | Release the model (queued last) |
| ~(cmacs-whisper-vad-list)~ | Open handles |

All VAD work goes through one ~GThreadPool~ with a single worker, so operations run in exactly the order Lisp issued them — a reset cannot overtake the feed before it, a close always runs last — and the worker alone owns each ~whisper_vad_context~.  Results return through ~g_main_context_invoke~ and the GC-rooted callback registry (~cmacs_dispatch_callback_register~), like transcription jobs.  A model that fails to load is remembered, so it costs one attempt, not one per feed.  Feed whole multiples of 512 samples (1024 bytes): a ragged tail is zero-padded by whisper.cpp and would skew the next window.  Sample buffers are wiped with ~memset_explicit~ before they are freed.

The model is ~cmacs-whisper-default-vad-model~ (~ggml-silero-v6.2.0.bin~), found through the same search path as whisper models; ~M-x cmacs-whisper-download-vad-model~ fetches it (about 1 MB) from ~cmacs-whisper-vad-download-base-url~ (the ~ggml-org/whisper-vad~ repository, which is not the one whisper models come from).

** PCM helpers

| DEFUN | Purpose |
|-------+---------|
| ~(cmacs-whisper-pcm-levels PCM &optional WINDOW)~ | Vector of RMS levels in dBFS (-120..0), one per complete WINDOW (512) samples — the voice loop's energy detector |
| ~(cmacs-whisper-pcm-resample PCM FROM TO)~ | Linear-interpolation resampler for mono S16LE, e.g. piper's 22050 Hz to 16000 Hz |

Both are single passes, cheap enough for the main thread.

These are what [[file:cmacs-voice-loop.org][cmacs-voice-loop.org]] (the always-on "Jarvis" loop) is built on.

* Quick Start

#+begin_src elisp
;; First-time setup
M-x cmacs-whisper-download-model RET ggml-base.en.bin RET

;; Synchronous transcribe
(cmacs-whisper-transcribe-file
  (cmacs-whisper-model-path)
  "/tmp/note.wav")
;; => ((:text . "the quick brown fox...")
;;     (:segments . (((:start . 0)   (:end . 1200) (:text . "the quick"))
;;                   ((:start . 1200) (:end . 2400) (:text . " brown fox..."))
;;                   ...)))

;; Async with callback
(cmacs-whisper-transcribe-async
  (cmacs-whisper-model-path) "/tmp/note.wav"
  (lambda (r) (message "got: %s" (cdr (assq :text r)))))

;; Optional trailing LANGUAGE and THREADS args (all four transcribe
;; DEFUNs accept them).  THREADS caps the CPU cores whisper.cpp uses
;; for the inference; nil or a non-positive value means "all cores"
;; (the historical default).  cmacs-transcribe passes 4 here by default.
(cmacs-whisper-transcribe-async
  (cmacs-whisper-model-path) "/tmp/note.wav"
  (lambda (r) (message "got: %s" (cdr (assq :text r))))
  "en" 4)
#+end_src

The full arities are:

- ~(cmacs-whisper-transcribe-file MODEL WAV &optional LANGUAGE THREADS)~
- ~(cmacs-whisper-transcribe-pcm MODEL PCM &optional LANGUAGE THREADS)~
- ~(cmacs-whisper-transcribe-async MODEL WAV CALLBACK &optional LANGUAGE THREADS)~
- ~(cmacs-whisper-transcribe-pcm-async MODEL PCM CALLBACK &optional LANGUAGE THREADS)~

* Live dictation (cmacs-whisper-dictate)

~M-x cmacs-whisper-dictate~ (bound to ~C-c v d~) toggles dictation into the current buffer.  Speech is cut into ~cmacs-whisper-dictate-window-seconds~ (3 s) windows; each is transcribed and inserted at point with ~undo-boundary~ between windows.  Windows go to whisper one at a time, so text lands in the order it was said, and a window with nothing above the energy floor is not sent at all (no ~[BLANK_AUDIO]~ in your prose).

*Insert as you talk.*  Every ~cmacs-whisper-dictate-partial-interval~ (1 s; nil to turn off) the window in progress is re-transcribed and shown, dimmed, at the insertion point as an overlay ~after-string~ — nothing reaches the buffer or its undo list until the window is final, when the real text replaces it.

*One microphone.*  Dictation is an exclusive client of the shared voice engine ([[file:cmacs-voice.org][cmacs-voice.org]]): the always-on loop pauses while you dictate, and a push-to-talk command elsewhere (VR, the brigade, ~C-c v v~) ends the dictation instead of opening the device a second time.  There is one dictation at a time; toggling in another buffer moves it there.  Stopping still transcribes what is left of the last window.

** Mode-line indicator

- 🎤 — recording, accumulating a window
- 🎤… — sending a window to whisper, awaiting result

** Voice commands

~cmacs-whisper-dictate-command-words~ is an alist intercepted before
text is inserted:

#+begin_src elisp
'(("new line"      . newline)
  ("new paragraph" . (lambda () (newline) (newline)))
  ("period"        . (lambda () (insert ?.)))
  ("question mark" . (lambda () (insert ??)))
  ("delete word"   . backward-kill-word)
  ("undo"          . undo))
#+end_src

Add your own by ~customize-variable~ or via DSL.

* MCP tool

The ~transcribe~ MCP tool is registered when both ~--with-cmacs-mcp~
and ~--with-cmacs-whisper~ are built.

#+begin_src json
{"name": "transcribe",
 "arguments": {"audio_path": "/tmp/note.wav", "language": "en"}}
#+end_src

Returns the transcript text in the result content block.  Related
read-only tools: ~list_whisper_models~, ~list_voices~.

* Troubleshooting

** Model not found

~cmacs-whisper-dictate~ raises ~user-error~ if
~(cmacs-whisper-model-path)~ doesn't exist.  Run
~M-x cmacs-whisper-download-model~ once.

** Slow inference

CPU only?  Try the tiny/base model.  For a Mac with Metal:
rebuild ~deps/whisper.cpp~ with ~WHISPER_COREML=1 make libwhisper.a~.
For NVIDIA: ~WHISPER_CUDA=1 make~.

** Empty transcription

Sample rate mismatch.  Confirm capture is 16 kHz:

#+begin_src elisp
(cmacs-audio-default-rate)  ;; should be 16000
#+end_src
