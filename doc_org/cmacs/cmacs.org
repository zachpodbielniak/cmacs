CMacs is GNU Emacs extended with GLib, GObject, Wayland, and embedded
scripting.  This manual covers every CMacs-specific subsystem.

* Opening This Manual

From inside CMacs:

- =M-x cmacs-manual= --- open this index
- =M-x cmacs-manual-topic= --- jump directly to a topic (with completion)

From any Org file, follow links with =C-c C-o= or =M-x org-open-at-point=.

The topic list offered by =cmacs-manual-topic= is discovered dynamically
from the installed doc tree, so both the core chapters below and the
embedded dependency docs (see [[*Dependency Documentation][Dependency Documentation]]) appear automatically.

* Dependency Documentation

Each vendored dependency under =deps/= ships its own =docs/= folder.  At
build time =tools/sync-deps-docs.sh= (invoked by the =cmacs-deps-docs=
Makefile target) mirrors every dependency's docs verbatim into
=doc_org/cmacs/deps/<dep>/=, which is installed and browsable alongside
this manual.  Files keep their original format --- =.org= open in Org
mode, =.md= in Markdown mode.

- [[file:deps/index.org][Embedded Dependency Index]] --- generated list linking into each dep
- Or run =M-x cmacs-manual-topic= and pick a =deps/...= entry

This tree is a generated build artifact (not committed); it is refreshed
on every build from the current submodule checkouts.

* Quick Start

#+begin_example
./install-deps            # system dependencies
./autogen.sh              # first time only
./configure               # auto-detects bundled deps
make -j$(nproc)           # builds everything
src/emacs                 # run it
#+end_example

Place config files in =~/.config/cmacs/=:

| File          | Language | Loaded by              |
|---------------+----------+------------------------|
| =init.el=     | Elisp    | Emacs (standard)       |
| =init.bacon=  | Shell    | =bacon-source=         |
| =init.c=      | C        | =crispy-run=           |

All three are loaded at startup in that order.
