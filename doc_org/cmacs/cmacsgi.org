#+TITLE: cmacsgi Command Reference
#+STARTUP: showall
#+OPTIONS: toc:3 num:t

* Overview

=cmacsgi= is a bacon shell builtin that provides 50+ commands for
controlling CMacs from the shell.  It works through the shared
[[file:api.org][CMacs API]] library with three transport backends:

- *FD* (socketpair) --- used by the bacon child process
- *D-Bus* --- used by external tools
- *DIRECT* (in-process) --- used by crispy scripts

Every command documented here is available from the bacon shell prompt:

#+begin_example
bacon> cmacsgi <command> [args...]
bacon> cmacsgi help
bacon> cmacsgi help <command>
#+end_example

** Launching with the builtin available

The =cmacsgi= command is registered by =cmacs_gi.so=, a Bacon module
loaded from =$CMACS_MODULE_DIR=.  The simplest way to get a session
where the env var is set correctly is the =just run= recipe:

#+begin_example
just run
M-x bacon
bacon> cmacsgi --help
#+end_example

=just run= exports =CMACS_MODULE_DIR=$PWD/cmacs/bacon/modules= so the
module loads in any =cmacs --bacon= subprocess (whether via =M-x
bacon= or run directly from the same shell).  See [[file:bacon.org::*Loading the cmacsgi builtin][bacon.org → Loading
the cmacsgi builtin]] for the full env-var story and what to do if you
prefer launching =cmacs= some other way.

* Buffer Commands

Group: =buf=

Manage open buffers --- list, create, kill, save, switch, inspect.

** buf list

List open buffers.

#+begin_example
cmacsgi buf list [-l]
#+end_example

| Flag | Description                                                   |
|------+---------------------------------------------------------------|
| =-l= | Long format: tab-separated name, file, modified, size, mode  |

#+begin_example
bacon> cmacsgi buf list
*scratch*
*Messages*
init.el

bacon> cmacsgi buf list -l
*scratch*	(none)	no	42	lisp-interaction-mode
*Messages*	(none)	no	1024	messages-buffer-mode
init.el	~/.emacs.d/init.el	no	2048	emacs-lisp-mode
#+end_example

** buf show

Print buffer content to stdout.

#+begin_example
cmacsgi buf show [NAME]
#+end_example

If NAME is omitted, shows the current buffer.

** buf create

Create an empty buffer.

#+begin_example
cmacsgi buf create NAME
#+end_example

** buf kill

Kill (close) a buffer.

#+begin_example
cmacsgi buf kill NAME
#+end_example

** buf save

Save a buffer to its associated file.

#+begin_example
cmacsgi buf save [NAME]
#+end_example

If NAME is omitted, saves the current buffer.

** buf save-as

Save a buffer to a new file path.

#+begin_example
cmacsgi buf save-as NAME PATH
#+end_example

** buf current

Print the current buffer name.

#+begin_example
bacon> cmacsgi buf current
*scratch*
#+end_example

** buf switch

Switch the editor to display a buffer.

#+begin_example
cmacsgi buf switch NAME
#+end_example

** buf info

Print buffer metadata as =key=value= pairs.

#+begin_example
cmacsgi buf info [NAME]
#+end_example

#+begin_example
bacon> cmacsgi buf info init.el
name=init.el
file=/home/zach/.emacs.d/init.el
modified=no
size=2048
mode=emacs-lisp-mode
point=1
line=1
col=0
#+end_example

** buf rename

Rename a buffer.

#+begin_example
cmacsgi buf rename OLD NEW
#+end_example

* Text Commands

Edit buffer text.  All accept =-b BUF= to target a specific buffer
(defaults to current buffer).

** insert

Insert text at point or at a specific position.

#+begin_example
cmacsgi insert [-b BUF] [-p POS] TEXT...
#+end_example

| Flag     | Description                              |
|----------+------------------------------------------|
| =-b BUF= | Target buffer (default: current)         |
| =-p POS= | Character position to insert at          |

Remaining arguments are joined with spaces as the text to insert.

#+begin_example
bacon> cmacsgi insert "Hello, world!"
bacon> cmacsgi insert -p 1 "Header: "
bacon> cmacsgi insert -b notes.org "New entry"
#+end_example

** delete

Delete a region and print the deleted text.

#+begin_example
cmacsgi delete [-b BUF] START END
#+end_example

START and END are character positions (1-indexed).

#+begin_example
bacon> cmacsgi delete 1 10
Hello, wo
#+end_example

** line

Print a specific line (or the current line).

#+begin_example
cmacsgi line [-b BUF] [N]
#+end_example

#+begin_example
bacon> cmacsgi line 42
(defun my-function ()
#+end_example

** append

Append text to the end of a buffer.

#+begin_example
cmacsgi append [-b BUF] TEXT...
#+end_example

* Search Commands

Search, replace, and filter buffer content.

** search

Search for a pattern in a buffer.

#+begin_example
cmacsgi search [-b BUF] [-r] [-c] [--] PATTERN
#+end_example

| Flag   | Description                            |
|--------+----------------------------------------|
| =-r=   | Use regexp (default: literal string)   |
| =-c=   | Count matches only (print number)      |
| =--=   | End of flags (pattern follows)         |

#+begin_example
bacon> cmacsgi search "defun"
42:  (defun my-function ()
87:  (defun another-function ()

bacon> cmacsgi search -r "def\(un\|var\|macro\)"
42:  (defun my-function ()
55:  (defvar my-var nil)

bacon> cmacsgi search -c "TODO"
7
#+end_example

** replace

Replace all occurrences of a pattern.  Prints the replacement count.

#+begin_example
cmacsgi replace [-b BUF] [-r] [--] PATTERN REPLACEMENT
#+end_example

| Flag | Description                  |
|------+------------------------------|
| =-r= | Use regexp                   |
| =--= | End of flags                 |

#+begin_example
bacon> cmacsgi replace "foo" "bar"
12

bacon> cmacsgi replace -r "v[0-9]+" "latest"
3
#+end_example

** occur

List all matching lines in grep format (=LINE_NUMBER:LINE_TEXT=).

#+begin_example
cmacsgi occur [-b BUF] PATTERN
#+end_example

#+begin_example
bacon> cmacsgi occur "TODO"
15:;; TODO: fix this hack
42:;; TODO: add error handling
99:;; TODO: write tests
#+end_example

#+end_example

#+begin_example

bacon> cmacsgi set inhibit-startup-screen t
bacon> cmacsgi set frame-title-format "CMacs: %b"

Print an Emacs variable's current value.

#+begin_example

#+end_example

#+begin_example

bacon> cmacsgi get fill-column
80
#+end_example

Load a color theme.

#+begin_example

#+end_example

#+begin_example

Set the default font face and optional size.

#+end_example

#+begin_example

* Monitor Commands

Group: =monitor=

Manage compositor outputs (monitors) when running in =--gowl= mode.

** monitor list

List connected monitor names, one per line.

#+begin_example
bacon> cmacsgi monitor list
WL-1
DP-1
#+end_example

** monitor info

Show monitor metadata as =key=value= pairs.

#+begin_example
cmacsgi monitor info NAME
#+end_example

#+begin_example
bacon> cmacsgi monitor info WL-1
name=WL-1
mode=1280x720@60
position=0,0
scale=1.000000
enabled=t
transform=0
#+end_example

** monitor modes

List advertised modes for a monitor.  Nested Wayland outputs
typically have no advertised modes (custom modes are used instead).

#+begin_example
cmacsgi monitor modes NAME
#+end_example

#+begin_example
bacon> cmacsgi monitor modes DP-1
2560x1440@144000
1920x1080@60000
1280x720@60000
#+end_example

** monitor set-mode

Set the output resolution.  Format is =WxH= or =WxH@RATE= where
RATE is in millihertz (60000 = 60 Hz).  Omit =@RATE= to match any
refresh rate.

#+begin_example
cmacsgi monitor set-mode NAME WxH[@RATE]
#+end_example

#+begin_example
bacon> cmacsgi monitor set-mode WL-1 1920x1080
bacon> cmacsgi monitor set-mode DP-1 2560x1440@144000
#+end_example

If the requested mode matches an advertised mode, it is used directly.
Otherwise a custom mode is created (common for nested Wayland
sessions where the parent compositor controls the actual window size).

** monitor position

Get the monitor's position in the output layout.

#+begin_example
cmacsgi monitor position NAME
#+end_example

#+begin_example
bacon> cmacsgi monitor position DP-1
1280,0
#+end_example

** monitor set-position

Set the monitor's position in the output layout.

#+begin_example
cmacsgi monitor set-position NAME X Y
#+end_example

#+begin_example
bacon> cmacsgi monitor set-position DP-1 1920 0
#+end_example

** monitor scale

Get or set the output scale factor.  Without FACTOR, prints the
current scale.  With FACTOR, sets it.

#+begin_example
cmacsgi monitor scale NAME [FACTOR]
#+end_example

#+begin_example
bacon> cmacsgi monitor scale WL-1
1.000000

bacon> cmacsgi monitor scale WL-1 2.0
bacon> cmacsgi monitor scale WL-1 0.8
bacon> cmacsgi monitor scale WL-1 1.0
#+end_example

Scale affects the logical resolution: at scale 2.0 on a 1280x720
output, the logical area shrinks to 640x360 (HiDPI).  At scale 0.8
it grows to 1600x900.  Clients automatically resize to fill the new
logical area.

** monitor transform

Get or set the output transform (rotation/flip).  Without VALUE,
prints the current transform.  With VALUE (0--7), sets it.

#+begin_example
cmacsgi monitor transform NAME [VALUE]
#+end_example

| Value | Meaning      |
|-------+--------------|
|     0 | normal       |
|     1 | 90°          |
|     2 | 180°         |
|     3 | 270°         |
|     4 | flipped      |
|     5 | flipped-90°  |
|     6 | flipped-180° |
|     7 | flipped-270° |

#+begin_example
bacon> cmacsgi monitor transform WL-1 1    ;; rotate 90°
bacon> cmacsgi monitor transform WL-1 0    ;; back to normal
#+end_example

** monitor enable

Enable a disabled monitor.

#+begin_example
cmacsgi monitor enable NAME
#+end_example

** monitor disable

Disable a monitor.

#+begin_example
cmacsgi monitor disable NAME
#+end_example

* C Runtime Introspection Commands

Group: =c=

The =c= group exposes the [[file:cintrospect.org][cintrospect]] (DWARF
self-introspection + libgccjit subprocess) and [[file:cpatch.org][cpatch]]
(runtime hot-patching) DEFUNs through the bacon shell.  Every
subcommand is a thin IPC bridge to the matching =cmacs-c-*= primitive
in the running editor — output is whatever =prin1= produces (plists,
lists, strings, integers).

| Subcommand                      | Underlying DEFUN              | Notes                                     |
|---------------------------------+-------------------------------+-------------------------------------------|
| =c list KIND [-g GLOB] [-n N]=  | =cmacs-c-list=                | KIND ∈ {symbol,defun,object}              |
| =c symbol NAME=                 | =cmacs-c-symbol-info=         | name, kind, addr, size, file, line        |
| =c type NAME=                   | =cmacs-c-type-info=           | struct/union/enum layout                  |
| =c source NAME=                 | =cmacs-c-function-source=     | (file . line) for a function              |
| =c addr 0xADDR=                 | =cmacs-c-addr-to-source=      | runtime addr → (file line fn)             |
| =c source-to-addr FILE LINE=    | =cmacs-c-source-to-addr=      | reverse lookup, prints =0xADDR=           |
| =c objects=                     | =cmacs-c-list-objects=        | loaded ELF objects + DWARF availability   |
| =c defuns [-g GLOB] [-n N]=     | =cmacs-c-list-defuns=         | every Lisp_Subr DEFUN                     |
| =c defun-info SYM=              | =cmacs-c-defun-info=          | arity + fn-addr + source                  |
| =c stack [-d N]=                | =cmacs-c-stack-trace=         | C stack via libdw (default depth 64)      |
| =c get NAME [TYPE]=             | =cmacs-c-symbol-value=        | TYPE ∈ {auto,int,str,lisp,hex,pointer}    |
| =c set NAME VALUE [TYPE]=       | =cmacs-c-symbol-set-value=    | mutation; refuses .rodata writes          |
| =c compile [-s SIG] FUNC FILE=  | =cmacs-c-compile=             | reads FILE locally, JIT via gcc           |
| =c call HANDLE [ARG...]=        | =cmacs-c-call=                | dispatches on signature                   |
| =c handle HANDLE=               | =cmacs-c-handle-info=         | metadata for a JIT handle                 |
| =c handle-dispose HANDLE=       | =cmacs-c-handle-dispose=      | dlclose + remove temp files               |
| =c patch SYM FN-NAME=           | =cmacs-c-patch-defun=         | resolves FN-NAME → addr in one eval       |
| =c unpatch SYM=                 | =cmacs-c-unpatch-defun=       | restore original                          |
| =c patches=                     | =cmacs-c-patch-list=          | list current patches                      |
| =c unpatch-all=                 | =cmacs-c-unpatch-all=         | panic button                              |

The four =patch*= subcommands probe =fboundp= on their target DEFUN.
If the editor was built without =--enable-cmacs-cpatch=, they print
=cpatch not enabled in this build (configure --enable-cmacs-cpatch)=
and return success — the cmacsgi surface stays uniform regardless of
build configuration.

** Quick start

Find every DEFUN whose name starts with =buffer-=:

#+begin_example
bacon> cmacsgi c defuns -g "buffer-*" -n 5
((:symbol-name "buffer-base-buffer" :c-name "Fbuffer_base_buffer" ...)
 (:symbol-name "buffer-chars-modified-tick" ...)
 ...)
#+end_example

Inspect a single DEFUN:

#+begin_example
bacon> cmacsgi c defun-info cons
(:symbol-name "cons" :c-name "Fcons" :min-args 2 :max-args 2
 :fn-addr 1407374883553792 :file "alloc.c" :line 2734)
#+end_example

Locate a C function in the source tree:

#+begin_example
bacon> cmacsgi c source make_buffer
("buffer.c" . 489)
#+end_example

Resolve a runtime address (from a backtrace, =:fn-addr=, or =/proc/PID/maps=):

#+begin_example
bacon> cmacsgi c addr 0x55bb7af23a90
("eval.c" 2351 "Feval_sub")
#+end_example

Walk the editor's C stack — handy from inside a shell pipeline that
just pinged the editor:

#+begin_example
bacon> cmacsgi c stack -d 8
((:addr ... :file "process.c" :line 5212 :function "wait_reading_process_output")
 (:addr ... :file "keyboard.c" :line 4015 :function "read_event_from_main_queue")
 ...)
#+end_example

** Read/write C globals

The cintrospect demo globals are good targets for round-trips:

#+begin_example
bacon> cmacsgi c get cmacs_cintrospection_test_int int
42

bacon> cmacsgi c set cmacs_cintrospection_test_int 100 int
t

bacon> cmacsgi c get cmacs_cintrospection_test_int int
100

bacon> cmacsgi c get cmacs_cintrospection_test_str str
"hello from C"
#+end_example

The =auto= type heuristic picks =lisp= for =Q=- and =V=-prefixed names of
size 8, =str= for char arrays, =int= for size-1/2/4/8 with integer-ish
naming, and =hex= for everything else.  Pass an explicit TYPE when
auto-detection would guess wrong.

** Hot-patching workflow (cpatch)

Compile a replacement, patch a DEFUN, exercise it, restore.

Write =/tmp/replace-cons.c=:

#+begin_src c
#include "lisp.h"
Lisp_Object my_cons (Lisp_Object car, Lisp_Object cdr) {
  /* trace each call before delegating to the original */
  fprintf (stderr, "my_cons called!\n");
  return Fcons (car, cdr);
}
#+end_src

Then from bacon:

#+begin_example
bacon> cmacsgi c compile -s "Lisp_Object(Lisp_Object,Lisp_Object)" \
                        my_cons /tmp/replace-cons.c
7

bacon> cmacsgi c handle 7
(:id 7 :fn-name "my_cons" :fn-addr 140736342847584
 :signature "Lisp_Object(Lisp_Object,Lisp_Object)" ...)

bacon> cmacsgi c patch cons my_cons
t

bacon> cmacsgi eval '(cons 1 2)'
(1 . 2)
# stderr (in cmacs): my_cons called!

bacon> cmacsgi c patches
((:kind defun-swap :symbol cons :original-addr ... :patched-addr ...))

bacon> cmacsgi c unpatch cons
t

bacon> cmacsgi c handle-dispose 7
t
#+end_example

If anything goes sideways:

#+begin_example
bacon> cmacsgi c unpatch-all
3
#+end_example

* Eval Command

Evaluate arbitrary elisp from the shell.

#+begin_example
cmacsgi eval EXPR...
#+end_example

All arguments are joined with spaces into a single expression.

#+begin_example
bacon> cmacsgi eval '(+ 40 2)'
42

bacon> cmacsgi eval '(format-time-string "%Y-%m-%d")'
"2026-04-05"

bacon> cmacsgi eval '(buffer-name)'
"*scratch*"

bacon> cmacsgi eval '(message "hello from bacon")'
"hello from bacon"
#+end_example

* Other Commands

** find-file

Alias for =open=.  Opens a file in the editor.

#+begin_example
cmacsgi find-file PATH
#+end_example

** message

Display a message in the Emacs echo area (minibuffer).

#+end_example

bacon> cmacsgi message "Build complete!"
#+end_example
