* Welcome

cmacs exposes a session-bus D-Bus service so external processes — shell
scripts, file managers, language clients, custom dashboards, other
editors, AI agents — can talk to a running cmacs through typed methods,
watch live state via Properties, and react to events via signals.

This subdirectory contains the canonical reference for that surface.
The texi mirror is at [[file:../../doc/cmacs/dbus/][doc/cmacs/dbus/]];
the two must stay in sync (=tools/sync-docs.sh=).

The unified events endpoint ([[file:events.org][events.org]],
=org.cmacs.Editor1.Events=) has shipped: a generic =Event= firehose plus
typed named signals for file / buffer / project / window / frame / editor
activity, with opt-in text and subsystem feeds.

=org.freedesktop.Notifications= is the one desktop-integration item
where cmacs is the *server* rather than a client:
=cmacs-notify-daemon-mode-global= claims the name when it is free and
implements the freedesktop specification, so a gowl session has a
notification daemon at all.  See the Notifications section of
[[file:../gowl.org][gowl.org]].
