#+TITLE: Method Reference
#+STARTUP: showall
#+OPTIONS: toc:3 num:t

Reference for every method on =org.cmacs.Editor1= as of Phase 1.
Phase 3 will add typed sub-interfaces; their methods will be
documented in their own files when they land.

D-Bus type signatures: =s= string, =i= int32, =u= uint32, =x= int64,
=t= uint64, =b= bool, =d= double, =as= array-of-string, =v= variant,
=o= object-path, =h= file descriptor, =()= no return.

* Core methods

** Eval

Evaluate an arbitrary elisp expression, return its =prin1= form.

| Field            | Value                          |
|------------------+--------------------------------|
| Signature        | =Eval (s expression) -> (s)=   |
| Errors           | =org.cmacs.Editor1.Error=      |
| Synchronous      | yes                            |
| Bypasses elisp?  | no — full =cmacs-dispatch-eval=|

#+begin_src shell
gdbus call --session --dest org.cmacs.Editor \
    --object-path /org/cmacs/Editor \
    --method org.cmacs.Editor1.Eval \
    '(format "%s on %s" (emacs-version) (system-name))'
# => ('"GNU Emacs 31.0.50 ... on hostname"',)
#+end_src

This is the universal escape hatch.  Anything reachable from elisp is
reachable from here.  That includes the entire cmacsgi command
surface, since cmacsgi handlers are also elisp emitters.

** FindFile

Open a file or URL in the editor.  No return value.

| Field            | Value                            |
|------------------+----------------------------------|
| Signature        | =FindFile (s path) -> ()=        |
| Errors           | =org.cmacs.Editor1.Error=        |

#+begin_src shell
gdbus call --session --dest org.cmacs.Editor \
    --object-path /org/cmacs/Editor \
    --method org.cmacs.Editor1.FindFile \
    /etc/hostname
#+end_src

Equivalent to =M-x find-file=, so TRAMP paths
(=/ssh:host:/path/to/file=) work too.

** Message

Display a message in the echo area.  Useful for ping-style debugging
or remote notifications.

| Field            | Value                            |
|------------------+----------------------------------|
| Signature        | =Message (s text) -> ()=         |

#+begin_src shell
gdbus call --session --dest org.cmacs.Editor \
    --object-path /org/cmacs/Editor \
    --method org.cmacs.Editor1.Message \
    "build complete in $(awk '{print $1}' /tmp/build.time)s"
#+end_src

** GiRequire

Load a GObject Introspection namespace (=GLib=, =Gtk=, =Soup=, ...)
into cmacs's GI bridge.

| Field            | Value                                            |
|------------------+--------------------------------------------------|
| Signature        | =GiRequire (s namespace, s version) -> (b)=      |

#+begin_src shell
gdbus call --session --dest org.cmacs.Editor \
    --object-path /org/cmacs/Editor \
    --method org.cmacs.Editor1.GiRequire \
    GLib 2.0
# => (true,)
#+end_src

Pass an empty version string to accept whatever's installed:

#+begin_src shell
gdbus call --session --dest org.cmacs.Editor \
    --object-path /org/cmacs/Editor \
    --method org.cmacs.Editor1.GiRequire \
    Gtk ""
#+end_src

** GiCall

Call a function from a previously loaded GI namespace.  Each argument
is passed as a string and read on the cmacs side as a Lisp
expression — bare words become strings, numbers pass through,
quoted strings stay quoted.

| Field            | Value                                                  |
|------------------+--------------------------------------------------------|
| Signature        | =GiCall (s namespace, s function, as args) -> (s)=     |

#+begin_src shell
# (g-get-user-name) → no args
gdbus call --session --dest org.cmacs.Editor \
    --object-path /org/cmacs/Editor \
    --method org.cmacs.Editor1.GiCall \
    GLib get_user_name '[]'

# (g-hostname-is-ascii-encoded "example.com") → one string arg
gdbus call --session --dest org.cmacs.Editor \
    --object-path /org/cmacs/Editor \
    --method org.cmacs.Editor1.GiCall \
    GLib hostname_is_ascii_encoded \
    '["example.com"]'
#+end_src

** GiListFunctions

List every function in a loaded namespace.

| Field            | Value                                          |
|------------------+------------------------------------------------|
| Signature        | =GiListFunctions (s namespace) -> (as)=        |

#+begin_src shell
gdbus call --session --dest org.cmacs.Editor \
    --object-path /org/cmacs/Editor \
    --method org.cmacs.Editor1.GiListFunctions \
    GLib | head -3
# => (['access', 'ascii_digit_value', 'ascii_dtostr', ...],)
#+end_src

* Compositor methods (when =--with-cmacs-gowl=)
:PROPERTIES:
:CUSTOM_ID: compositor-methods
:END:

Bypass the elisp eval round-trip for compositor-control hot paths.
Each one returns a JSON-encoded string for structured fields and
=t=/=nil= strings for booleans (matching the cmacsgi convention).

These are on *=org.cmacs.Editor1.Compositor=* at =/org/cmacs/Editor=.
They used to live on =org.cmacs.Editor1= with a =Gowl= prefix, and
lost the prefix when they moved, because the interface name now
carries that context.  =GowlSetMfact= on =org.cmacs.Editor1= is
=SetMfact= on =org.cmacs.Editor1.Compositor=; the old names do not
resolve at all.

| Method                     | Signature       | Arguments / description                        |
|----------------------------+-----------------+------------------------------------------------|
| =ListClients=              | =() -> (s)=     | Every Wayland client, as JSON                  |
| =FocusedClient=            | =() -> (s)=     | The focused client, JSON or ="nil"=            |
| =FindClient=               | =(ss) -> (s)=   | pattern, by (="title"= / ="app-id"=)           |
| =FocusClient=              | =(ss) -> (s)=   | pattern, by                                    |
| =CloseClient=              | =(ss) -> (s)=   | pattern, by                                    |
| =SetClientGeometry=        | =(ssiiii) -> (s)= | pattern, by, x, y, width, height             |
| =Spawn=                    | =(s) -> (s)=    | Launch a command with =$WAYLAND_DISPLAY= set   |
| =SetLayout=                | =(s) -> (s)=    | ="tile"= / ="float"= / ="monocle"=             |
| =SetMfact=                 | =(d) -> (s)=    | Master-area split                              |
| =SetNmaster=               | =(i) -> (s)=    | Master-window count                            |
| =ViewTags=                 | =(u) -> (s)=    | Visible tag mask                               |
| =WorkspaceList=            | =() -> (s)=     | Workspaces, as JSON                            |
| =WorkspaceSwitch=          | =(i) -> (s)=    | Switch to workspace by id                      |
| =AddRule=                  | =(ssubi) -> (s)= | app_id, title, tags, floating, monitor        |
| =AddKeybind=               | =(sis) -> (s)=  | key, action-id, arg                            |
| =AddKeybindFull=           | =(siss) -> (s)= | key, action-id, arg, desc                      |
| =RunKeybind=               | =(s) -> (s)=    | Run what a key is bound to                     |
| =ListKeybinds=             | =() -> (s)=     | Bound keys with action nick, arg and desc      |
| =Lock= / =Unlock=          | =() -> (s)=     | Toggle the session lock                        |
| =Screenshot=               | =(ssss) -> (s)= | mode, client, by, file                         |
| =ReloadConfig=             | =() -> (s)=     | Reload the gowl config                         |
| =ConfigGet=                | =(s) -> (s)=    | Read a top-level config property               |
| =SetScreensaverWallpaper=  | =(s) -> (s)=    | Animated screensaver wallpaper (config name)   |
| =StopScreensaverWallpaper= | =() -> (s)=     | Stop the animated wallpaper                    |
| =ListScreensaverConfigs=   | =() -> (s)=     | List screensaver config names                  |
| =ScreensaverStatus=        | =() -> (s)=     | Renderer status                                |
| =ScreensaverPause= / =-Resume= / =-Restart= | =() -> (s)= | Control the renderer          |
| =ScreensaverSetFps=        | =(i) -> (s)=    | Renderer frame rate                            |

=AddKeybindFull= exists rather than a fourth argument on =AddKeybind=
because a D-Bus signature is part of the contract and callers already
use the =(sis)= form.  An empty =desc= means none.

=RunKeybind= runs the action a key is bound to *without* the key being
pressed.  Note this is not what the input-injection calls do: those
hand a key to the focused client and never consult the keybind table.

** Examples
:PROPERTIES:
:CUSTOM_ID: compositor-examples
:END:

#+begin_src shell
# Resize the master area.
gdbus call --session --dest org.cmacs.Editor \
    --object-path /org/cmacs/Editor \
    --method org.cmacs.Editor1.Compositor.SetMfact 0.7

# Move the external monitor to (1920, 0) and disable the laptop panel.
gdbus call --session --dest org.cmacs.Editor \
    --object-path /org/cmacs/Editor \
    --method org.cmacs.Editor1.Monitor.SetPosition \
    HDMI-A-1 1920 0
gdbus call --session --dest org.cmacs.Editor \
    --object-path /org/cmacs/Editor \
    --method org.cmacs.Editor1.Monitor.SetEnabled \
    eDP-1 false
#+end_src

The same surface is reachable as =emacsctl compositor ...= and
=emacsctl monitor ...=, which is usually less typing.

* AI methods (when =--with-cmacs-ai=)

On =org.cmacs.Editor1.Ai=, mirroring the MCP tool surface in
=cmacs/mcp/cmacs-mcp-tools-ai.c= -- the two are kept in sync
deliberately, so a method here has a tool there and vice versa.

Every one of these blocks the target's main thread for the whole call.
That is seconds for a prompt, and tens of seconds for a tool loop or an
image.

| Method          | Signature        | Description                                   |
|-----------------+------------------+-----------------------------------------------|
| =ListProviders= | =-> (s)=         | Provider symbols                              |
| =ListModels=    | =(s) -> (s)=     | provider (empty = all) → JSON                 |
| =Prompt=        | =(ssss) -> (s)=  | prompt, provider, system, model               |
| =Call=          | =(ssssb) -> (s)= | as =Prompt= + tools (multi-turn agent loop)   |
| =OpenChat=      | =(sss) -> (s)=   | provider, prompt, model → buffer name         |
| =GenerateImage= | =(ssssss) -> (s)= | prompt, provider, model, aspect, references, buffer |

An empty string means "unset" for every optional argument.

=GenerateImage= inserts the result into a buffer of the target instance:
attached to the current Org node where that is possible, otherwise saved
under =cmacs-ai-image-dir=.  =references= is a comma-separated list of
input images, each =PATH= or =PATH::ROLE=; the role tells the model what
that reference is for.  It is one flat string rather than an array
because the MCP bridge's schema translator cannot carry a nested list,
and the two surfaces share a wire format.

** Examples

Always target a specific instance.  A bare bus name reaches whichever
cmacs answers first, which on a desktop is the user's live session.
The per-instance name is =org.cmacs.Editor.Pid<N>= (every instance
acquires one; the unsuffixed =org.cmacs.Editor= goes to whichever got
there first), and the object path is =/org/cmacs/Editor= for every
interface:

#+BEGIN_SRC sh
gdbus call --session \
  --dest org.cmacs.Editor.Pid$(pgrep -n emacs) \
  --object-path /org/cmacs/Editor \
  --method org.cmacs.Editor1.Ai.GenerateImage \
  'a brass telescope' 'gemini' '' '16:9' '' ''
#+END_SRC

In practice =emacsctl ai generate-image= is the better front end; see
[[file:../emacsctl/commands.org][emacsctl commands]].

* Error handling

Every method that takes elisp returns errors as
=org.cmacs.Editor1.Error= D-Bus errors.  In =gdbus= they print as:

#+begin_example
Error: GDBus.Error:org.cmacs.Editor1.Error: ((wrong-number-of-arguments) ...)
#+end_example

Programmatic clients should match on the error name to decide whether
to surface to the user or retry.  Most languages' D-Bus bindings turn
the error into a typed exception (=DBusException= in Python, =Error=
in Rust zbus, etc.).  See [[file:cli-examples.org][cli-examples.org]]
for examples in each language.

* org.cmacs.Editor1.Brigade

Drives AI agents. Every argument and every return value is a string, so a shell
caller never has to think about D-Bus types; numeric arguments are coerced on
the far side. All of these route through =cmacs-brigade-call-tool=, the same
entry point an agent reaches over MCP — three surfaces, one code path.

| Method | Arguments | Returns |
|--------+-----------+---------|
| =Spawn= | =task=, =agent=, =title=, =model= (all but the first may be empty) | the new task id |
| =Status= | =id= | state, turns, tokens, cost |
| =Result= | =id= | what the task produced |
| =Cancel= | =id= | confirmation |
| =List= | — | every known task with its state |
| =Agents= | — | agent definitions available to spawn |
| =Providers= | — | AI providers this cmacs can reach |
| =Models= | =provider= | that provider's models, as =provider/model= |
| =Send= | =id=, =message= | queues a message; wakes a task that has already finished |
| =Inbox= | =id= | messages queued but not yet delivered |
| =Drop= | =id=, =index= (empty clears the queue) | how many were removed |
| =Log= | =id=, =from_turn=, =kinds= (both may be empty) | the transaction log |
| =Close= | =id= | releases the conversation's session |

=Send= continues an existing conversation rather than starting a new one, so the
agent still remembers everything from earlier turns. =Log= works on any task,
including ones the caller never spawned — see the mailbox chapter of the AI
Brigade manual.

Confirmation prompts are bypassed on this interface deliberately. They exist so
an *agent* cannot start paid work unattended; a D-Bus caller is the session
owner, who already has =org.cmacs.Editor1.Eval= on the same bus. It also could
not work as written: RPC evals bind =inhibit-interaction=, so a prompt inside a
dispatch signals rather than asking, and every =Spawn= would fail.

The bus name is =org.cmacs.Editor= and the object path
=/org/cmacs/Editor=; only the *interface* carries the =1=.

#+begin_src bash
busctl --user call org.cmacs.Editor /org/cmacs/Editor \
  org.cmacs.Editor1.Brigade Send ss "$ID" "now check the error paths too"

busctl --user call org.cmacs.Editor /org/cmacs/Editor \
  org.cmacs.Editor1.Brigade Log sss "$ID" "2" ""
#+end_src
