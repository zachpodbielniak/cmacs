#+TITLE: emacsctl Command Reference
#+STARTUP: showall
#+OPTIONS: toc:2 num:nil

* Global flags

Accepted anywhere on the command line:

| Flag                | Meaning                                          |
|---------------------+--------------------------------------------------|
| =-c=, =--context=   | use a named context from the config file         |
| =--instance SEL=    | target instance: =<pid>=, =primary=, or =auto=   |
| =--host DEST=       | remote editor over ssh (=user@machine=)          |
| =-o=, =--output=    | =table= (default), =json=, =yaml=, =raw=         |
| =-w=, =--watch=     | stream changes where supported (=logs=)          |
| =--timeout SECS=    | RPC timeout (default 30; long evals may need more) |
| =--config PATH=     | config file (default =~/.config/cmacs/emacsctl.yaml=, or =$EMACSCTL_CONFIG=) |
| =-q=, =--quiet=     | suppress non-essential output                    |
| =--version=         | client version                                   |
| =-h=, =--help=      | contextual help (see below)                      |

Precedence: command-line flags > the selected context > config
=settings:= > built-in defaults.

* Getting help

Help is contextual and available everywhere (all generated through
GLib's option parser, so flag listings can never drift from the
parser):

#+begin_src sh
  emacsctl --help                   # global: commands, groups, options
  emacsctl get --help               # a group: all of get's subcommands
  emacsctl logs --help              # a command: its flags + globals
  emacsctl help get content-org     # `help WORDS…' == `WORDS… --help'
#+end_src

A bare group (=emacsctl get=) prints the same subcommand listing and
exits 2; an unknown flag exits 2 with a =--help= hint; a typo'd verb
gets a did-you-mean suggestion.

* Org buffers: =get content-org=

=get content BUFFER= prints a buffer verbatim.  For org-mode buffers,
=get content-org= parses the document *in the editor* (org's own
parser — =org-map-entries=, planning info, property drawers, the
agenda match syntax) and returns a structured tree, so =-o yaml= /
=-o json= give you real data instead of a text blob:

#+begin_src sh
  emacsctl get content-org notes.org                # outline table
  emacsctl get content-org notes.org -o yaml        # nested tree
  emacsctl get content-org notes.org --match "/TODO" -o json
  emacsctl get content-org notes.org --match "work+urgent" --depth 2
  emacsctl get content-org notes.org --no-body --no-properties
#+end_src

| Flag                | Meaning                                        |
|---------------------+------------------------------------------------|
| =--match EXPR=      | org agenda match string: tags/todo/property    |
|                     | queries like =work+urgent/TODO= or =/DONE=     |
| =--depth N=         | limit headline depth                           |
| =--no-body=         | structure only, drop entry body text           |
| =--no-properties=   | drop property drawers                          |

Each headline carries =title=, =level=, =todo=, =priority=, =tags=,
=scheduled= / =deadline= / =closed=, =properties=, =body=, and
=children=; the document carries =buffer=, =file=, and the =#+TITLE= /
=#+AUTHOR= / =#+DATE= / =#+FILETAGS= keywords.  Keys are omitted when
empty, so the YAML stays tight.  The default table output renders an
indented outline (level, todo, title, tags, scheduled).

#+begin_src sh
  # All TODO deadlines this file knows about, as JSON:
  emacsctl get content-org work.org --match "/TODO" --no-body \
    -o json | jq -r '.. | .deadline? // empty'
#+end_src

* Output formats

#+begin_src sh
  emacsctl get buffers                # aligned table (human)
  emacsctl get buffers -o json        # pretty JSON array
  emacsctl get buffers -o yaml        # YAML sequence
  emacsctl get buffers -o raw         # one name per line, stable
  emacsctl eval '(+ 1 2)' -o raw      # "3" — byte-exact, no newline
#+end_src

- *table* — aligned columns with an upper-case header for lists;
  =key: value= lines for documents; scalars verbatim.
- *json* — the canonical data, pretty-printed (indent 2).
- *yaml* — same data through yaml-glib.
- *raw* — for scripts: scalars byte-exact, lists one-per-line,
  documents as compact one-line JSON.

* Examples

#+begin_src sh
  # Save every modified buffer whose name ends in .org:
  emacsctl get buffers -o raw \
    | grep '\.org$' \
    | while read -r b; do emacsctl buffer save "$b"; done

  # Jump the compositor to whatever workspace firefox is on:
  emacsctl compositor find firefox -o json | jq .

  # Editor health one-liner for a status bar:
  emacsctl describe instance -o json | jq -r .uptime

  # Hot-patch a C primitive, then verify:
  emacsctl c patch some-defun my_replacement_fn
  emacsctl c patch-log
#+end_src
