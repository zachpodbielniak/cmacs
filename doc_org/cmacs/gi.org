#+TITLE: GObject Introspection
#+STARTUP: showall
#+OPTIONS: toc:2 num:t

* Overview

The GI bridge lets you call any GObject Introspection-registered library
directly from Elisp.  Load a typelib with =gi-require=, then call
functions with =gi-call=.

* Elisp Primitives

| Function                                         | Description                                         |
|--------------------------------------------------+-----------------------------------------------------|
| =(gi-require NAMESPACE &optional VERSION)=       | Load a GI namespace (e.g., "Gtk" "4.0")            |
| =(gi-call NAMESPACE FUNCTION &rest ARGS)=        | Call a GI function, return result as string         |
| =(gi-enum NAMESPACE ENUM-TYPE MEMBER)=           | Look up an enum value by name                       |
| =(gi-flags NAMESPACE FLAGS-TYPE &rest MEMBERS)=  | Combine flag values by name                         |
| =(gi-list-functions NAMESPACE)=                  | List all functions in a loaded namespace             |
| =(gi-function-info NAMESPACE FUNCTION)=          | Return parameter/return type info for a function    |

** Examples

#+begin_src emacs-lisp
;; Get the current user name via GLib
(gi-require "GLib")
(gi-call "GLib" "get_user_name")
;; => "zach"

;; Look up an enum value
(gi-enum "GLib" "ChecksumType" "sha256")
;; => 2

;; List available functions
(gi-list-functions "GLib")
;; => ("get_user_name" "get_host_name" "get_home_dir" ...)

;; Use Gtk
(gi-require "Gtk" "4.0")
(gi-call "Gtk" "init")

;; A boxed struct comes back usable, with its methods a gi-method away
(let ((ctx (gi-call "GLib" "main_context_default")))
  (gi-method ctx "pending"))
;; => nil
#+end_src

** Values crossing the bridge

- Objects and interfaces are wrapped GObjects; registered boxed structs (=GMainContext=, =GDateTime=, =GBytes=, ...) are wrapped boxed values that =gi-method= accepts as an instance and any GI function accepts as a struct parameter.  A plain C struct with no GType stays =nil=.
- Enums and flags are integers; =GType= parameters and returns are type-name strings; =gunichar= is a character.
- Ownership follows the annotation.  A =transfer full= return -- every constructor's -- is released once the Lisp wrapper holds its own reference, and a returned string's buffer is freed after it is copied.  Before this, every object a GI call returned kept one reference for the life of the process.
- =gobject-new= and =gi-method= find a type's typelib entry by stripping the namespace's own C prefix (=g_irepository_get_c_prefix=), which is =G= for Gio, GLib and GObject rather than the namespace name; the name-based strip remains a fallback.

* High-Level Elisp Interface

The =cmacs-gi-require= function provides auto-generation of Elisp
wrapper functions.  After calling =(cmacs-gi-require "Gio")=, you can
call GI functions as =(gio-get-default)= etc.

#+begin_src emacs-lisp
;; Auto-generate wrappers for Gio
(cmacs-gi-require "Gio")

;; Now call Gio functions directly
(gio-app-info-get-all)
#+end_src
