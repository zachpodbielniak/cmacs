#+TITLE: Bar Widgets Reference
#+STARTUP: showall
#+OPTIONS: toc:2 num:t

* Overview

The gowl bar module provides 25 configurable widgets for system
monitoring, media, network, development, and custom command output.

Widgets are specified as a space-separated string in the bar
configuration:

#+begin_src emacs-lisp
(gowl-bar-configure
  '(("widgets" . "cpu load memory swap temp gpu disk:/ io net volume media wifi ip vpn git todo podman uptime host user keymap weather clock")))
#+end_src

Each widget supports a per-type color via =TYPE-color= config keys.
Some widgets accept parameters via colon syntax: =disk:/home=,
=net:wlp2s0=, =cmd:~/script.sh=, =weather:London=.

* Tag Indicator

Independent of the right-side widget list, the bar draws a dwm-style
*tag indicator* at its left edge: one numbered box per tag (1--9).
It reads the monitor's selected tag set and scans the compositor's
clients for occupied / urgent tags, repainting live as tags and
windows change.  See also the [[file:../gowl.org][gowl manual]] "Tags
and Workspaces" chapter.

The tag boxes are *clickable*: left-click views that tag on the
monitor whose bar you clicked, right-click toggles the tag's
visibility.  (Handled compositor-side in =on_cursor_button= via the
=GowlBarProvider= =tag_at= hit-test, so it works without any Elisp.)

| Box state | Colour keys                       |
|-----------+-----------------------------------|
| selected  | =tag-active-bg= / =tag-active-fg= |
| urgent    | =tag-urgent-bg= / =tag-urgent-fg= |
| occupied  | (bar bg) / =tag-occupied-fg=      |
| empty     | (bar bg) / =tag-empty-fg=         |

Toggle the whole row with the =show-tags= key (default on):

#+begin_src emacs-lisp
(gowl-bar-configure
  '(("show-tags" . "true")
    ("tag-active-bg" . "#89b4fa")
    ("tag-active-fg" . "#1e1e2e")
    ("tag-occupied-fg" . "#cdd6f4")
    ("tag-urgent-bg" . "#f38ba8")
    ("tag-urgent-fg" . "#1e1e2e")
    ("tag-empty-fg" . "#6c7086")))
#+end_src

** Per-widget refresh interval =@N=

Any widget can take a trailing =@N= suffix to override its refresh
interval in seconds.  This works for every widget type, not just
=cmd=, and wins over the global =cmd-interval= config key.

#+begin_src emacs-lisp
(gowl-bar-configure
  '(("widgets" . "cpu@1 memory disk:/@60 cmd:~/bin/pomo@1 weather:London@900 clock")))
#+end_src

Setting a fast interval on one widget also speeds up the bar tick so
it can reach that rate (bar ticks at =min(2s, fastest @N)=, floor 1s).
Slow intervals don't slow the tick down -- those widgets simply use
their cached output across redraws.

The last =@= is the delimiter, so commands that legitimately contain
=@= still parse: =cmd:ssh user@host@5= becomes (=ssh user@host=,
interval 5).  If the text after the final =@= is not a positive
integer, the whole token is treated as the widget spec.

* CMD Widget: Custom Command Output

The =cmd= widget runs an arbitrary shell command and displays its
first line of output.

Tilde paths (=~/bar/script.sh=) are expanded to =$HOME= at spawn time
because =g_spawn= bypasses the shell.

#+begin_src emacs-lisp
(gowl-bar-configure
  '(("widgets" . "cmd:~/bar/weather.sh cmd:~/bar/vpn-status.sh clock")
    ("cmd-interval" . "15")))  ;; global default for cmd widgets
#+end_src

** ANSI Color Support

The =cmd= widget supports ANSI escape sequences for colored output.
Colors are applied *only to ASCII printable characters* (0x20-0x7E).
Unicode characters (emojis, CJK, etc.) render in the widget's base
color, ensuring consistent display.

Supported ANSI sequences:
- =\033[0m= -- reset to default
- =\033[30m= - =\033[37m= -- standard 8 colors
- =\033[90m= - =\033[97m= -- bright 8 colors
- =\033[38;5;Nm= -- 256-color palette
- =\033[38;2;R;G;Bm= -- 24-bit truecolor

** Example: Colored status script

#+begin_src bash
#!/bin/bash
# ~/bar/status.sh
if systemctl is-active --quiet my-service; then
    echo -e "\033[32mSVC OK\033[0m 🟢"
else
    echo -e "\033[31mSVC DOWN\033[0m 🔴"
fi
#+end_src

The =SVC OK= / =SVC DOWN= text renders in green/red.
The emoji renders in the default foreground color.

* Git Widget

The =git= widget determines the current working directory from the
focused Wayland client's process (via =/proc/PID/cwd=), walks up
to find a =.git/= directory, reads the branch from =.git/HEAD=,
and counts dirty files via =git status --porcelain=.

Display format: =BRANCH= (clean) or =BRANCH*N= (N dirty files).

Works automatically when any terminal or editor is focused in a
git repository.

* Todo Widget (Elisp-driven)

The =todo= widget displays text pushed from Elisp via the
=widget-data-todo= config key:

#+begin_src emacs-lisp
;; Push todo count every 30 seconds
(run-with-timer 5 30
  (lambda ()
    (when (gowl-running-p)
      (gowl-bar-configure
        '(("widget-data-todo" .
           ,(format "TODO %d"
              (length (org-map-entries nil "/TODO" 'agenda)))))))))
#+end_src

* Network Widgets

** =net= -- Throughput

Delta-based byte rate calculation from =/proc/net/dev=.
Auto-detects the first non-lo interface, or specify: =net:wlp2s0=.

** =wifi= -- Signal Strength

Reads signal level in dBm from =/proc/net/wireless=.

** =ip= -- Local IP

Uses =getifaddrs()= for the first non-lo IPv4 address.
Specify interface: =ip:eth0=.

** =vpn= -- Status

Checks if =tun0= or =wg0= network interface exists in
=/sys/class/net/=.

* Multiple Bars (top + bottom)

The bar module supports two independent slots per compositor: one at
the top edge of the monitor, one at the bottom.  Each slot keeps its
own widgets, height, colors, font, title, and visibility flag.  The
compositor subtracts BOTH bar heights from the usable window area, so
tiling, vanitygaps, roundcorners, and =gowl-embed-app= automatically
respect both edges with no extra configuration.

The top slot is enabled by default (with the standard cpu/memory/
disk/battery/clock widgets).  The bottom slot stays dormant until you
configure it with a =("position" . "bottom")= entry.

** From Elisp

#+begin_src emacs-lisp
;; Top bar (same as before — this is the default slot)
(gowl-bar-configure
  '(("widgets" . "cpu memory disk battery clock")
    ("height"  . "28")))

;; Bottom bar — explicit position key activates the second slot
(gowl-bar-configure
  '(("position" . "bottom")
    ("widgets"  . "cmd:~/bin/scripts/tasks@5 clock")
    ("height"   . "24")
    ("bg-color" . "#181825")))
#+end_src

Convenience wrappers prepend the position key for you:

#+begin_src emacs-lisp
(cmacs-gowl-bar-configure-top
  '(("widgets" . "cpu memory disk battery clock")))

(cmacs-gowl-bar-configure-bottom
  '(("widgets" . "cmd:~/bin/scripts/tasks clock")
    ("height"  . "24")))
#+end_src

** Hiding / showing / resizing a slot

All per-slot DEFUNs take an optional POSITION symbol (=top= or
=bottom=, default =top=):

#+begin_src emacs-lisp
(gowl-set-bar-visible nil 'bottom)   ;; hide the bottom bar
(gowl-set-bar-visible t   'bottom)   ;; show it again
(gowl-set-bar-height 32 'top)        ;; taller top bar
(gowl-bar-height 'bottom)            ;; => 24
(gowl-bar-set-title "build: ok" 'bottom) ;; per-slot title
#+end_src

Hiding a slot clears its surfaces and re-runs =arrangelayers=, so the
tiling area grows back immediately.  The slot's configuration is
preserved across hide/show cycles.

** From cmacsgi (bacon shell)

#+begin_example
bacon> cmacsgi bar configure bottom widgets="clock" height=24
bacon> cmacsgi bar configure top widgets="cpu memory disk battery clock"
bacon> cmacsgi bar height bottom
24
bacon> cmacsgi bar hide bottom
bacon> cmacsgi bar show bottom
bacon> cmacsgi bar title "hello" top
#+end_example

The =cmacsgi bar= subcommand takes an optional position token right
after the action.  =bar configure= expects =KEY=VALUE= arguments; all
other keys follow the same syntax as =gowl-bar-configure=.

** From crispy / C

No crispy-specific binding is needed — call through =cmacs_eval()=:

#+begin_src c
cmacs_eval(api,
  "(gowl-bar-configure "
  "'((\"position\" . \"bottom\") "
  "  (\"widgets\"  . \"clock\") "
  "  (\"height\"   . \"24\")))");
#+end_src

* Configuration Reference

All keys are passed via =gowl-bar-configure=.  The (optional)
=position= key selects which bar slot the settings apply to; all
other keys act per-slot.

| Key                | Default         | Description                         |
|--------------------+-----------------+-------------------------------------|
| =position=         | =top=           | Target slot: =top= or =bottom=      |
| =widgets=          | cpu mem disk bat clock | Space-separated widget list   |
| =show-tags=        | =true=          | Draw the left-edge tag indicator    |
| =tag-active-bg=    | =#89b4fa=       | Selected-tag fill                   |
| =tag-active-fg=    | =#1e1e2e=       | Selected-tag number                 |
| =tag-occupied-fg=  | =#cdd6f4=       | Occupied (non-selected) number      |
| =tag-urgent-bg=    | =#f38ba8=       | Urgent-tag fill                     |
| =tag-urgent-fg=    | =#1e1e2e=       | Urgent-tag number                   |
| =tag-empty-fg=     | =#6c7086=       | Empty-tag number                    |
| =height=           | 28              | Bar height in pixels                |
| =bg-color=         | =#1e1e2e= (80%) | Background color (hex + alpha)      |
| =fg-color=         | =#cdd6f4=       | Default text color                  |
| =font=             | =monospace 13=  | Pango font description              |
| =TYPE-color=       | (use fg-color)  | Per-widget color (e.g. =cpu-color=) |
| =cmd-interval=     | 10              | Global default for cmd re-runs (per-widget =@N= wins) |
| =widget-data-KEY=  | --              | Push data for Elisp-driven widgets  |
| =title-delimiters= | --              | Chars that split title segments     |
| =title-palette=    | --              | Space-separated hex colors          |
