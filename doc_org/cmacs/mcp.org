#+TITLE: CMacs MCP Server
#+STARTUP: showall
#+OPTIONS: toc:2 num:t

* Overview

CMacs embeds an MCP (Model Context Protocol) server directly in Emacs,
giving AI agents full access to the editor runtime over a Unix domain
socket.  The server starts automatically at init and listens on
=$XDG_RUNTIME_DIR/cmacs-mcp-PID.sock=.

MCP clients (Claude Code, other AI tools) connect through the
=cmacs-mcp= shim binary, which relays stdio to the socket.  Once
connected, an agent can evaluate Elisp, read and write buffers,
control windows, send keystrokes, manage processes, run GObject
Introspection calls, and operate the Gowl Wayland compositor --- all
through structured MCP tool calls.

* Architecture

#+begin_example
MCP Client (e.g. Claude Code)
  |
  |  stdin/stdout (NDJSON)
  v
cmacs-mcp  (shim binary)
  |
  |  Unix domain socket (NDJSON)
  v
McpUnixSocketServer  (inside Emacs)
  |
  |  GLib main context dispatch
  v
Emacs runtime  (eval, buffers, windows, ...)
#+end_example

The =cmacs-mcp= shim is a small GIO-based relay that reads NDJSON
lines from stdin and forwards them to the socket, and vice versa.
This lets any MCP client that speaks stdio connect without knowing
about Unix sockets.

Inside Emacs, the =McpUnixSocketServer= is attached to the CMacs
=GMainContext= (see [[file:glib.org][GLib Event Loop]]).  Tool callbacks run through the
=cmacs_dispatch_eval= mechanism to safely evaluate Lisp, respecting
the =waiting_for_input= guard.

Multiple concurrent client sessions are supported.

* Tools

The server exposes tools in eleven categories.

** eval --- Elisp Evaluation

| Tool                  | Description                                        |
|-----------------------+----------------------------------------------------|
| =eval=                | Evaluate an Elisp expression, return result        |
| =describe_function=   | Describe an Elisp function (docstring, arglist)    |
| =describe_variable=   | Describe an Elisp variable (docstring, value)      |
| =apropos=             | Search for symbols matching a pattern              |
| =completions=         | Get completion candidates for a prefix             |

The =eval= tool is the universal gateway --- any Emacs functionality
is reachable through it.

** buffer --- Buffer Management

| Tool                  | Description                                        |
|-----------------------+----------------------------------------------------|
| =list_buffers=        | List all buffers with metadata                     |
| =get_buffer_content=  | Read text content of a buffer (with optional range) |
| =set_buffer_content=  | Replace buffer content or insert at point          |
| =create_buffer=       | Create a new buffer with optional content          |
| =kill_buffer=         | Kill a buffer by name                              |
| =switch_to_buffer=    | Switch to a buffer                                 |
| =save_buffer=         | Save a buffer to its file                          |
| =find_file=           | Open a file in a buffer                            |

** window --- Window and Frame Control

| Tool                  | Description                                        |
|-----------------------+----------------------------------------------------|
| =list_windows=        | List all windows with buffer and geometry info     |
| =list_frames=         | List all frames                                    |
| =split_window=        | Split a window horizontally or vertically          |
| =delete_window=       | Delete a window                                    |
| =select_window=       | Select (focus) a window                            |

** input --- Keyboard and Commands

| Tool                  | Description                                        |

** project --- Workspace Files

Generic file tools scoped to the open project, for a remote
"copilot" agent connected over the bridge.  Every path is resolved
against the workspace root --- =cmacs-mcp-workspace-root= if set,
otherwise the project.el root, otherwise =default-directory= --- and,
unless =cmacs-mcp-workspace-confine= is nil, confined to it so a
remote client cannot escape the project tree.

| Tool                  | Description                                        |
|-----------------------+----------------------------------------------------|
| =project_root=        | Return the absolute workspace root path            |
| =project_read_file=   | Read a file's raw contents (path relative to root) |
| =project_write_file=  | Write a file, creating parent directories          |
| =project_list_files=  | List the entries of a workspace directory          |
| =project_find_files=  | Recursively find files by name regexp (=.git= skipped) |

* Resources

MCP resources expose Emacs state as readable URIs.

| URI Pattern             | Description                                      |
|-------------------------+--------------------------------------------------|
| =buffer://{name}=       | Text content of an Emacs buffer by name          |
| =file://{path}=         | Read a file from the filesystem                  |
| =messages://=           | Contents of the =*Messages*= buffer              |
| =variable://{name}=     | Current value of an Elisp variable               |
| =process://{name}=      | Output buffer of a named subprocess              |
| =keybinds://=           | All gowl keybindings as JSON (gowl builds)       |
| =screenshot://frame=    | A fresh PNG screenshot of the desktop (gowl builds) |

* Prompts

Prompt templates provide structured context for AI interactions.

** debug_session

Start a debug session with full Emacs context: backtrace, recent
messages, optional buffer content, and process info.

| Argument         | Required | Description                               |
|------------------+----------+-------------------------------------------|
| =error_message=  | no       | Error message or symptom to investigate   |
| =buffer=         | no       | Buffer name to include in context         |

** code_review

Review code in an Emacs buffer with file info and content.

| Argument         | Required | Description                               |
|------------------+----------+-------------------------------------------|
| =buffer=         | no       | Buffer to review (defaults to current)    |

** gowl_layout

Compositor state context: current layout, clients, monitors, and
workspaces.  Available on gowl builds; takes no arguments.

** automation_author

Authoring context for podomation: loaded modules, active pods, and
engine status.  Available on podomation builds; takes no arguments.

* cmacs-mcp Shim Binary

The =cmacs-mcp= binary is a stdio-to-socket relay that lets MCP
clients connect to the embedded server.

** Socket Discovery Order

1. =--socket PATH= flag (explicit full path)
2. =--name NAME= flag (expands to =$XDG_RUNTIME_DIR/cmacs-mcp-NAME.sock=)
3. =$CMACS_MCP_SOCKET= environment variable
4. Auto-discover: scan =$XDG_RUNTIME_DIR/cmacs-mcp-*.sock=, pick newest

** Usage Examples

#+begin_src shell
# Auto-discover (picks the most recently created socket)
cmacs-mcp

# Connect to a specific socket
cmacs-mcp --socket /run/user/1000/cmacs-mcp-12345.sock

# Connect by name
cmacs-mcp --name myproject

# Override via environment
CMACS_MCP_SOCKET=/tmp/test.sock cmacs-mcp
#+end_src

** Claude Code Configuration

Add to your MCP client config (e.g. =.claude/settings.json=):

#+begin_src json
{
  "mcpServers": {
    "cmacs": {
      "command": "cmacs-mcp"
    }
  }
}
#+end_src

* Elisp Primitives

| Function                              | Description                                    |
|---------------------------------------+------------------------------------------------|
| =(cmacs-mcp-server-p)=               | Return non-nil if the MCP server is running    |
| =(cmacs-mcp-socket-path)=            | Return the Unix socket path, or nil            |
| =(cmacs-mcp-session-count)=          | Return the number of active client sessions    |
| =(cmacs-mcp-start)=                  | Start the MCP server                           |
| =(cmacs-mcp-stop)=                   | Stop the MCP server and disconnect all clients |

** Minor Mode

=cmacs-mcp-mode= is a global minor mode that tracks buffer
modifications so MCP resource subscriptions (e.g. =buffer://=)
receive update notifications.

#+begin_src emacs-lisp
;; Enable buffer change notifications for MCP clients
(cmacs-mcp-mode 1)

;; Check server status
(cmacs-mcp-status)
#+end_src
