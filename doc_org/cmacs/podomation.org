#+TITLE: Podomation Automation Engine
#+AUTHOR: Zach Podbielniak
#+STARTUP: showall

* Overview

Podomation is a GObject-native, event-driven automation engine with 80+
modules, a custom DSL, REPL, admin API, and state persistence.  CMacs
embeds it via =pod_engine_start_embedded()=, running on the existing
GMainContext without a separate event loop.

Enable with =--with-cmacs-podomation= at configure time.

* Architecture

** Embedding Model

CMacs uses =PodRepl= to create the engine internally.  The REPL's
engine (obtained via =pod_repl_get_engine()=) is THE engine --- REPL and
DEFUNs share the same module manager and pod namespace.

The engine runs on the default =GMainContext= integrated into Emacs's
=pselect()= loop via =cmacs-glib-loop.c=.  No separate thread or event
loop is needed.

** Built-in Modules

Two =PodModule= subclasses are compiled into =temacs= (not loaded as
=.so= plugins).  They are registered with =pod_module_manager_register()=
during =cmacs-podomation-start=, after the plugin =.so= files load:

- =cmacs= -- bridges Emacs events and eval into the DSL
- =gowl= -- bridges compositor events and commands (requires =--with-cmacs-gowl=)

Both are DUAL modules implementing =PodEventSource= and
=PodEventHandler= interfaces via =G_DEFINE_FINAL_TYPE_WITH_CODE= with
=G_IMPLEMENT_INTERFACE=.

** Lisp Eval Safety

The cmacs module's =eval= and =eval_async= handlers use =g_idle_add()=
to post work to the GMainContext.  This avoids the =waiting_for_input=
SIGABRT crash that would occur if Lisp were evaluated synchronously from
a GLib dispatch callback.

The gowl module's handlers call =cmacs_dispatch_gowl_*()= functions
directly --- no idle dispatch needed since they don't evaluate Lisp.

** pdumper Safety

The =PodEngine= is never created during C init.  =init_cmacs_podomation()=
is intentionally empty.  The engine is created from Elisp only, making
it pdumper-safe.

* DSL Reference

** Pod Declaration

#+begin_example
pod name = module_name->new(arg1, arg2);
#+end_example

** Event Binding

#+begin_example
name->event_name => handler->function(args);
#+end_example

** Result Capture

#+begin_example
res result := name->event => handler->function(args);
res persist result := name->event => handler->function(args);
#+end_example

=persist= results survive across event dispatches.

** Pipe Chain

#+begin_example
name->event => handler1->func(args) | handler2->func("{pipe->field}");
#+end_example

Each handler's output becomes the next handler's =pipe= scope.

** Where Guard

#+begin_example
name->event where result->field == "value" => handler->func(args);
#+end_example

Comparison operators: ~==~, ~!=~, ~<~, ~>~, ~<=~, ~>=~, ~=~~
(regex), ~!~~ (negated regex).

** Conditional

#+begin_example
if result->field == "value" {
    name->event => handler->func(args);
} else {
    name->event => handler->other(args);
}
#+end_example

** Retry with Circuit Breaker

#+begin_example
name->event => retry(3, backoff: "exponential") {
    res r := handler->func(args) circuit_breaker(threshold: 5, reset: "1m");
} on_failure => log->write_error("failed: {error}");
#+end_example

** Parallel Block

#+begin_example
name->event => parallel {
    res a := handler1->func(args);
    res b := handler2->func(args);
};
#+end_example

** Interpolation

#+begin_example
"{result->field}"              property access on a result
"{result->field[key]}"         nested dict key lookup
"{pipe->field}"                current pipe stage value
"{pipe[N]->field}"             Nth pipe stage (0-based)
"${ENV_VAR}"                   environment variable
"$(command)"                   shell substitution (stdout)
"{field|regex(\"pat\",\"rep\")}" inline regex substitution
#+end_example

** Regex Operators

~=~~ matches against PCRE patterns.  After a match, capture groups
populate =rematch->= scope:

#+begin_example
source->on_event
    where event->message =~ "(?P<action>Accepted|Failed) .* for (?P<user>\\w+)"
    => log->write_info("{rematch->action} for {rematch->user}");
#+end_example

| Scope              | Meaning              |
|--------------------+----------------------|
| =rematch->0=       | Full match           |
| =rematch->1=       | First capture group  |
| =rematch->name=    | Named group          |
| =rematch->count=   | Number of groups     |
| =rematch->matched= | ="true"= or ="false"= |

** Event Name Patterns

#+begin_example
name->on_*               glob: matches on_tick, on_message, ...
name->on_t?ck            glob: single wildcard char
name->/on_(get|post)/    regex: enclosed in /.../ delimiters
#+end_example

** Operators Summary

| Operator | Use                      | Example                        |
|----------+--------------------------+--------------------------------|
| ~->~     | Member access / call     | =timer->new(1000)=             |
| ~=>~     | Event binding            | =t->on_tick => log->write(...)= |
| ~=~      | Pod declaration only     | =pod t = timer->new(...)=       |
| ~:=~     | Result capture           | =res r := source->event => ...= |
| ~\vert~  | Pipe to next handler     | =h1->f() \vert h2->g(...)=       |
| ~==~     | String equality guard    | =where r->status == "200"=      |
| ~!=~     | Inequality               | =where r->code != "0"=          |
| ~=~~     | Regex match (PCRE)       | =where e->path =~ "^/api"=      |
| ~!~~     | Negated regex match      | =where e->ua !~ "bot"=          |

* REPL

Open an interactive REPL buffer:

: M-x podomation-repl

The REPL uses =comint-mode= with tab completion.

From the bacon shell:

: pod repl

Built-in REPL commands start with ~:~:

| Command         | Description                        |
|-----------------+------------------------------------|
| =:modules=      | List loaded modules                |
| =:pods=         | List active pods                   |
| =:vars=         | List result variables              |
| =:undef <name>= | Remove a pod (stops it) or variable |
| =:load <file>=  | Load and execute a =.pod= file     |
| =:reset=        | Reset engine state                 |
| =:describe <m>= | Full module help text              |
| =:help=         | Show help                          |
| =:quit=         | Exit the REPL                      |

DSL text entered at the prompt is parsed and executed immediately.
Multi-line input is supported (the prompt changes to =...>=).

Tab completion works for module names, event names, handler names,
and REPL commands.

* Hook Bridge

The Elisp layer bridges Emacs hooks to podomation events in =snake_case=.
Hooks are installed by =cmacs-podomation--install-hooks= (called
automatically by =cmacs-podomation-start-with-config=).

** Default Hook Mappings

| Emacs Hook          | Podomation Event   | Event Data                          |
|---------------------+--------------------+-------------------------------------|
| =after-save-hook=   | =on_buffer_save=   | =buffer_name=, =file_name=, =major_mode= |
| =kill-buffer-hook=  | =on_buffer_kill=   | =buffer_name=                        |
| =after-init-hook=   | =on_after_init=    | (none)                              |
| =post-command-hook= | =on_post_command=  | =command_name=                       |

** Dynamic Hook Registration

Register any Emacs hook as a podomation event source:

#+begin_src emacs-lisp
(cmacs-podomation-hook "compilation-finish-functions")
#+end_src

This fires an =on_hook= event with =hook_name= data whenever the named
hook runs.  Use from DSL with a =where= guard:

#+begin_example
pod c = cmacs->new();
c->on_hook
    where event->hook_name == "compilation-finish-functions"
    => gotify->send("Compilation finished");
#+end_example

*** DSL Examples

#+begin_example
pod c = cmacs->new();

/* Log every buffer save */
c->on_buffer_save => log->write_info("saved: {event->file_name}");

/* Notify on compilation failure */
c->on_compile_finish
    where event->exit_code != "0"
    => cmacs->notify("Build Failed", "{event->buffer_name}");

/* Shell command with pipe to capture output */
pod t = timer->new(60000);
t->on_tick => cmacs->shell_command("uptime")
           | log->write_info("uptime: {pipe->stdout}");

/* Save all buffers on idle */
pod idle = cmacs->new();
idle->on_idle => cmacs->save_all();

/* Write results to a file */
c->on_buffer_save
    => cmacs->shell_command("date +%H:%M")
     | cmacs->append_file("/tmp/save-log.txt",
         "{pipe->value} saved {event->file_name}\n");

/* Query buffer state in a pipe */
t->on_tick => cmacs->buffer_name()
           | cmacs->shell_command("echo editing: {pipe->value}");

/* Compile on save for specific modes */
c->on_buffer_save
    where event->major_mode == "rust-mode"
    => cmacs->compile("cargo check");

/* Open a file from DSL */
cmacs->find_file("/tmp/notes.org");
#+end_example

(gi-require "Podomation" "1.0")

    where event->status_code != "200"
    => slack->send("#alerts", "API unhealthy: {event->status_code}");
#+end_example

#+end_example
